### Made with Python 3.13.5

### To install requirements run:
`pip install -r requirements.txt`

### Data Setup:
- This app requires the **`cleaned_vhi_data.csv`** file.
- **Note:** You must obtain this file by running your **Lab 2** script and placing it in this folder.

### To run:
- `cd ZPAD_lab5`
- `streamlit run ZPADlab5.py`
