# LAB 6: OpenCV Camera Processing

Програма для захоплення відео з камери та обробки в реальному часі.

### Вимоги:
- ОС: Ubuntu 20.04+ (або інший Linux)
- Камера: Веб-камера (USB або інтегрована)
- Бібліотеки: OpenCV 4.x

### Як запустити:
1. Встановіть залежності: `sh preinstall.sh`
2. Зберіть проєкт: `sh build.sh`
3. Запустіть: `sh run.sh`

### Керування:
- `1` — Звичайний режим
- `2` — Чорно-білий (Grayscale)
- `3` — Детекція країв (Canny)
- `4` — Розмиття (Blur)
- `ESC` або `q` — Вихід
