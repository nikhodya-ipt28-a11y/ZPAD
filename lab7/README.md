# LAB 7: AI-Powered Multi-threaded Camera Processing

##  Про проєкт
Програма для захоплення відео з камери з паралельною обробкою: фільтрами (OpenCV) та детекцією облич за допомогою нейромережі (DNN).

### ⚡ Ключові особливості:
- **Multithreading:** AI-детекція винесена в окремий потік (Worker Thread) для збереження високого FPS.
- **AI Model:** Використано ResNet-10 (Caffe) для детекції облич (input 300x300).
- **Синхронізація:** Обмін даними між потоками через `std::mutex` та `std::atomic`.
- **Модульність:** Кожна логічна частина винесена в окремий клас (.hpp/.cpp).
